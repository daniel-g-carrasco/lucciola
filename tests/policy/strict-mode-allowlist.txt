# Shell scripts allowed to run without `set -euo pipefail`, each with the
# reason. Read by .github/scripts/check-strict-mode.py (lint, the policy
# job): every other tracked shell script under build_files/, lucciola/,
# .github/scripts/, .github/smoke/ and tests/ must set -e, -u and pipefail
# in its first 30 lines. An entry here without a reason, for a file that is
# gone, or for a script that is strict after all, fails the check.
#
#   <path>  <why -e (or -u, or pipefail) would be wrong here>
#
# Two families account for nearly all of it. Validators, probes and
# diagnostics run every check and count or print the failures: with -e the
# first failing check would end the run and the rest would never be
# reported, which is the "check that cannot fail" shape in reverse (a check
# that cannot finish). Helpers that decide what to do from the result of
# each command (a missing file, a pgrep with no match, an unmet condition)
# handle every failure on the spot, and -e would turn a handled case into
# an exit before the handling.
